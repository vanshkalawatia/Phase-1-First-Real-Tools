# Phase 1: First Real Tools

**WEEKS 3–5**

Now you’re building things that **save data**. These projects are still command-line tools, but they have state.

| **Project** | **What it teaches** | **What you actually build** |
| --- | --- | --- |
| **5. CLI Expense Tracker** | File I/O (JSON), `try/except`, loops, functions | A tool that adds expenses, saves them to a JSON file, and shows the total. |
| **6. Task List Manager** | File I/O, lists, dictionaries, string methods | A tool that adds, removes, and lists tasks, saving them to a file. |
| **7. Weather CLI** | `requests`, JSON parsing, API keys, environment variables | A tool that fetches weather for a city and prints the forecast. |

## GATE

You have three working CLI tools with READMEs. Anyone can clone them and run them on any machine.
